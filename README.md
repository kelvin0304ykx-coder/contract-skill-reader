# 合同Skill读者包

版本：0.1.0，采用[MIT许可证](LICENSE)。可学习、修改、商业使用和再分发，须保留版权及许可声明；按现状提供，不保证特定审查结果。

把现有合同、委托立场和修改范围交代清楚，按任务输出带真实修订的DOCX、修改理由，或前期整理/签署核对清单。此包整理自已有合同审查流程，保留精准修订、母稿身份、理由对应及实际文件验收要求。

先看[中文上手说明](docs/中文上手说明.md)，再看[依赖与兼容性](docs/依赖与兼容性.md)、[实测结果](docs/测试结果.md)和[许可说明](docs/许可状态.md)。包中有一份完全虚构的维护合同与三种委托示例，不包含真实客户材料。适用范围是既有合同审阅；不包含新合同起草、诉讼、采购投标制作或对外提交。

## 下载和开始

公开仓库：[kelvin0304ykx-coder/contract-skill-reader](https://github.com/kelvin0304ykx-coder/contract-skill-reader)。

1. 点击仓库页面绿色 **Code → Download ZIP**，或[直接下载完整ZIP](https://github.com/kelvin0304ykx-coder/contract-skill-reader/archive/refs/heads/main.zip)；解压后进入含有`README.md`和`requirements.txt`的目录。
2. 按[中文上手说明](docs/中文上手说明.md)创建Python虚拟环境、安装依赖并运行`doctor`。
3. 用`tools/reader.py init`创建一种练习，在练习目录调用项目Skill，发送`任务.txt`。三种委托各用新目录。
4. 重开实际产物，对照修改理由和条款，检查修订、批注、分页及签署区；失败和待确认项保留。

下载ZIP不等于已经安装运行环境。模型工具、账号、法律原文渠道和文档软件由使用者另备；不通过评论或私信领取。

## 包里有什么

- `skills/legal-contract-review-reader/`：完整流程、配套引用和只读OOXML校验器；没有必须另装的私人Skill。
- `examples/原件/维护服务合同.docx`：虚构练习合同，故意缺少附件一及邮箱确认文件。
- `examples/委托示例/`：代表乙方审改、未说明代表方整理、乙方签署前核对。
- `tools/reader.py`：检查Python依赖、创建新练习目录、只读提取DOCX文字；不调用模型、不开通账号、不自动审合同。
- `requirements.txt`：本次练习推荐的Python依赖版本，模型和文档软件另备。
- `docs/测试结果.md`：本包实际隔离测试的结果和边界，不拿此前本机副本测试冒充本轮结果。

## 三类练习的预期交付

| 练习 | 用户委托 | 应交内容 |
|---|---|---|
| redline | 代表乙方审改 | 另存带修订/必要批注的DOCX及按条款对应的修改理由；不直接交清洁签署稿 |
| intake | 立场未明确，先整理 | 当前事实、方向、缺口及应澄清事项；不擅自选择一方修改合同 |
| signing | 乙方签署前核对 | 材料、正文实质问题和签署栏分开列的核对清单；不因填日期就无条件放行 |

这些是委托范围，不是标准答案，不要求输出固定条数。修订理由以实际改动为准，新增期限、费率或责任上限仍需双方确认。

## 使用边界

模型执行环境、账户、法律数据库、文档软件和相关服务费用不随包提供。原文检索缺失时，能继续文本及商业分析，不能凭记忆作确定法律效力结论。完整DOCX交付仍需真实打开、查看修订和逐页验收。

一个虚构样本不能证明其他合同审查准确率，也不直接产生可签定稿。阅读和修改真实业务材料前应遵守所在机构的权限、保密及文件管理要求。
