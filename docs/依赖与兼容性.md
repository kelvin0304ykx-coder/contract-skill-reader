# 依赖与兼容性

| 依赖 | 用途 | 包内提供 |
|---|---|---|
| 本地模型执行工具及有效登录 | 理解委托、读写文件、运行脚本 | 不提供模型、账户或登录配置；本轮用已安装Codex CLI |
| Python 3.11+ | 辅助工具、只读OOXML校验 | 仅提供脚本，不捆绑Python |
| python-docx 1.2.0、lxml 6.1.0、typing_extensions 4.15.0 | 本次推荐文档处理依赖 | requirements.txt；不捆绑第三方库源文件或安装包 |
| Word/WPS/兼容文档软件或可靠渲染器 | 实际打开DOCX、修订/批注与逐页版面核对 | 不提供商业软件、不自动安装、不测试授权 |
| 获准法律原文渠道 | 需要效力、法条和现行规则判断时核验 | 不提供数据库/MCP/账号；按Skill引用记录来源和缺口 |

`tools/reader.py`与随包OOXML校验器使用Python标准库；`doctor`按本练习推荐的编辑环境检查第三方库。依赖可用与法律业务正确是不同结论。

独立虚拟环境默认不共享系统site-packages。它是Python依赖隔离，不是虚拟机，也不能隔离模型服务、操作系统和宿主文档软件。模型工具应按其自身权限规则限制任务范围。

读者版已经去除必须依赖个人`documents`或法律路由Skill的入口；所有本包必需Markdown引用及校验脚本都在目录中。法律检索与实际文档软件以可用能力接入，不因没有某个私人Skill名就假装已经完成。

可选的私人研究链、经验索引及其脚本未放入包，也不初始化。新合同起草、诉讼、采购投标制作、企业背景调查、平台提交都没有因本包安装而获得授权或实现。

本地审阅阶段尚未签发跨平台兼容承诺；本轮实际入口、依赖版本、测试状态及失败见测试结果.md。macOS/Linux安装命令属于指导形式，未在这些系统实测。Microsoft Word界面未验时，不把WPS导出记录写成Word验证。
